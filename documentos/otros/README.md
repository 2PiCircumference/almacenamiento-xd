# 📦 Otros Documentos

Guarda aquí cualquier otro tipo de documento que no encaje en las categorías anteriores.

## Ejemplos:
- Archivos de código fuente
- Archivos de configuración (JSON, YAML, XML)
- Archivos comprimidos (ZIP, RAR)
- Archivos de audio
- Archivos de video
- Formatos especializados

## Organización:
Considera crear subcarpetas para organizar mejor diferentes tipos de documentos.
