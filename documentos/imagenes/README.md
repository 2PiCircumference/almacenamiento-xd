# 🖼️ Imágenes

Guarda aquí tus archivos de imagen.

## Formatos soportados:
- PNG - Mejor para gráficos y capturas de pantalla
- JPG/JPEG - Mejor para fotografías
- GIF - Para animaciones simples
- SVG - Gráficos vectoriales escalables
- WebP - Formato web moderno

## Usos con IA:
- Análisis de imágenes
- Extracción de texto (OCR)
- Reconocimiento de objetos
- Generación de descripciones
- Edición asistida por IA
