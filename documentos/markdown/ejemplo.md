# Ejemplo de Documento Markdown

Este es un ejemplo de documento en formato Markdown.

## ¿Por qué usar Markdown?

Markdown es ideal para:
- Documentación técnica
- Notas estructuradas
- README files
- Blogs y artículos

## Formato Básico

**Negrita** se hace con doble asterisco.

*Cursiva* se hace con un solo asterisco.

### Listas

1. Primer elemento
2. Segundo elemento
3. Tercer elemento

### Enlaces y Código

Puedes incluir [enlaces](https://github.com) y `código inline`.

```python
# Bloque de código
def ejemplo():
    return "Hola Mundo"
```

### Tablas

| Columna 1 | Columna 2 | Columna 3 |
|-----------|-----------|-----------|
| Dato 1    | Dato 2    | Dato 3    |
| Dato 4    | Dato 5    | Dato 6    |

---

Markdown es perfecto para trabajar con IA porque es fácil de leer tanto para humanos como para máquinas.
