# 📄 PDFs

Guarda aquí tus documentos PDF.

## Tipos de PDFs útiles para IA:
- Artículos científicos
- Libros y capítulos
- Manuales y guías
- Formularios
- Informes y reportes
- Documentación técnica

## Nota:
Algunos modelos de IA pueden procesar PDFs directamente, mientras que otros pueden requerir que extraigas el texto primero.
